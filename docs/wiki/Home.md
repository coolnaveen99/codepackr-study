## Principles

1. Make every tool useful without requiring an account.
2. Keep student-entered information in the browser where possible.
3. Explain concepts before asking students to use a calculator or utility.
4. Keep examples, sample data, reset and copy/export actions consistent.
5. Prefer accessible responsive UI over decorative complexity.
